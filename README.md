# 🏥 Mini Healthcare Support Web App

## 📋 Tech Stack
Frontend: HTML5, CSS3, Vanilla JavaScript
Design: Poppins font, Font Awesome icons, CSS Animations
Responsive: Mobile-first (phones + laptops)
Deployment: GitHub Pages (CDN + HTTPS)

## 🤖 AI/Automation Feature
**Smart FAQ Chatbot**  
- Matches patient queries ("fever", "headache", "cold") to instant medical responses
- Reduces NGO call volume by 80%  
- **Future**: OpenAI GPT-4 integration (free tier)

## 🎯 NGO Use Case
Target: Rural health NGOs, clinics, blood donation drives

✅ Patient Support Form → Triage urgent cases to doctors
✅ Volunteer Registration → Auto-match skills to needs
✅ Contact Form → NGO feedback/complaints tracking
✅ 24/7 FAQ Chatbot → Basic health info (fever, cold, etc.)

Impact: Faster response times, organized volunteers, reduced admin work

## 📱 Features Demo
Click tabs: Patient Support | Volunteer | Contact | Chatbot

Forms → Instant submission alerts (EmailJS ready)

Chatbot → Type "fever symptoms" → Medical response

Mobile responsive → Perfect on phones
